# npx

## Usage

    $ npx typescript-starter
    
    # 推荐：SPA 友好，5 秒搞定
    $ npx serve -s dist

    $ npx serve .                 # 当前目录，端口 3000
    $ npx serve -s dist           # SPA 模式，Vue/React history 路由刷新不 404
    $ npx serve -l 8080           # 指定端口
    $ npx serve -C                # 开启 CORS
    $ npx serve -l 0.0.0.0:8080   # 局域网可访问

    $ npx http-server
