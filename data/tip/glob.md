# Glob 语法


Glob 语法是一种用于匹配文件路径名的模式规则，它使用通配符来指定一个或多个文件。它比正则表达式更简单，主要用于在命令行或程序代码中快速筛选文件。

核心通配符

通配符 含义 示例

* 匹配任意数量（包括0个）的任意字符（除了路径分隔符，如 / 或 \）。 *.txt 匹配所有 .txt 文件。

? 匹配单个任意字符。 file?.log 匹配 file1.log，但不匹配 file10.log。

[...] 匹配括号内列出的任意一个字符。支持范围 [a-z] 和取反 [!0-9]。 file[0-9].txt 匹配 file0.txt 到 file9.txt。

高级用法

•   **/：在支持递归的现代工具中（如 git、find 的 -glob 选项），用于匹配零个或多个目录层级。

    ◦   示例：**/*.js 会匹配当前目录及所有子目录中的 .js 文件。

•   {a,b,c}：匹配一组用逗号分隔的选项。

    ◦   示例：*.{jpg,png,gif} 匹配所有 .jpg、.png 和 .gif 文件。

典型使用场景

1.  命令行操作：ls *.py、rm temp_*.log
2.  编程中匹配文件：在 Python 的 glob 模块、Node.js、Webpack 配置等中广泛使用。
3.  配置文件：在 .gitignore 文件中忽略特定模式的文件。

与正则表达式的主要区别

•   目的不同：Glob 用于匹配文件名和路径，语法简单直观；正则表达式用于匹配文本内容，功能强大但复杂。

•   通配符不同：Glob 用 * 表示任意多个字符，正则表达式用 .*。

简单来说，当你想按名字快速找出一组文件时，用 Glob；当需要深入分析或提取文本内容时，用正则表达式。



## 示例

```shell
$ with-watch exec --input "**/*.rs" cargo run
```
